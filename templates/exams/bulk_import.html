Formatting guide

Three import formats are supported.

Format 1 (all question types): each question starts with a TYPE: line — MCQ, TF, ENUM, IDENT, CASE, or MATCH.

TYPE: MCQ
Q: What is the capital of France?
POINTS: 2
A) Paris *
B) London
C) Berlin
D) Madrid

TYPE: TF
Q: The Philippines has 7,641 islands.
POINTS: 1
ANSWER: True

TYPE: IDENT
Q: What is H2O commonly known as?
POINTS: 1
KEY: Water
KEY: H2O

TYPE: ENUM
Q: Name 3 branches of government.
POINTS: 3
EXPECTED: 3
KEY: Executive
KEY: Legislative
KEY: Judicial

TYPE: MATCH
Q: Match each term in Column A with the correct definition in Column B.
POINTS: 3
PAIR: SaaS = Software as a Service
PAIR: IaaS = Infrastructure as a Service
PAIR: PaaS = Platform as a Service
DISTRACTOR: Network as a Service
  • POINTS: optional, defaults to 1.
  • Multiple Choice: mark the correct choice by ending its line with *.
  • True/False: just add an ANSWER: True or ANSWER: False line.
  • Enumeration / Identification / Case Analysis: list accepted answers or keywords with KEY:, one per line.
  • Matching Type: list each Column A/B pair with PAIR: left = right (needs at least 2), plus optional DISTRACTOR: text lines for extra Column B options with no correct match. Column B is shown to students in random order.

Format 2 (quick Multiple Choice only): no TYPE: line needed — just the question, lettered choices, and an answer line.

What is Google Sheets mainly used for?
A. Video editing
B. Organizing and analyzing data
C. Playing games
D. Designing websites
Answer Key: B
  • Choice lines can use "A." or "A)".
  • The answer line can say "Answer Key: B", "Answer: B", or "Ans: B".
  • Every Format 2 question is worth 1 point.

Format 3 (Programming Multiple Choice): number each question and separate the question text, code, and choices with blank lines. Mark exactly one trailing choice with *.

1. Analyze the output of the code.

num1 = 5
num2 = 10
print("Hello World!", num1 + num2)

A. Hello World
B. Hello World! 5
C. 5
D. Hello World! 15 *
  • The code may contain blank lines, tabs, indentation, and asterisks.
  • Only an asterisk at the end of a choice marks it correct.
  • Start each following question with a numbered line such as 2. after the previous choices.

For Formats 1 and 2, leave a blank line between questions. Keep Programming Multiple Choice questions together in their own import. Image Identification is created in the question editor because its image cannot be included in a text import.
